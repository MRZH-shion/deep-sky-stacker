## 2. Star databases

Generated with [tetra3](https://github.com/esa/tetra3) (Apache-2.0, © ESA) from the
**Hipparcos main catalogue** (ESA, 1997).

- `dsso_narrow.npz` (4°–8°) is generated by this project and distributed as a Release
  asset, not in the repository.
- `dsso_database.npz` (10°–30°) is the same file as tetra3's bundled
  `data/default_database.npz`, so it is not redistributed here; the program falls back to
  tetra3's copy when it cannot find its own.

Hipparcos is ESA public science data, free to use in research and engineering. Academic use
should cite *The Hipparcos and Tycho Catalogues*, ESA SP-1200 (1997).

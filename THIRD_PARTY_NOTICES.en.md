## 3. Things to watch when distributing binaries

1. **LibRaw is LGPL-2.1, not MIT.**
   - LibRaw is unmodified and called as a **separate DLL** (`raw_r.dll`), which satisfies the
     LGPL dynamic-linking requirement.
   - Obligations: state the name and licence, and point to the LibRaw sources
     (<https://www.libraw.org/>).
   - With a **onefile exe** the DLL is packed inside and extracted to a temp directory at
     runtime, which makes replacement awkward. Pack with **onedir** if you want
     `raw_r.dll` to be visibly replaceable.

2. **PyInstaller's GPL exception** covers "building with it" only; it does not change your
   program's licence.

3. **Do not commit NVIDIA's CUDA libraries.**
   `cudart / nvrtc / nvjitlink / cublas / cufft / cusolver / cusparse / curand` under
   `gpu_runtime/` are **NVIDIA proprietary** (`LicenseRef-NVIDIA-Proprietary`). The CUDA
   Toolkit EULA allows redistribution **as part of an application** but forbids separate
   distribution or sublicensing.
   - This repository does **not** contain them (see `.gitignore`).
   - Users install `pip install cupy-cuda12x` themselves to get the matching runtime.
   - Without `gpu_runtime/` the program falls back to CPU mode with full functionality.
